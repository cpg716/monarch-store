# Instructions
1. **Validate:** Always run the `check` alias (`cargo check`) in `src-tauri/` before attempting a build.
2. **Execute:** Launch the development server using the `dev` alias (`npm run tauri dev`).
3. **Verify:** Check backend logs and confirm `cargo check` passes.
